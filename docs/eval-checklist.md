- [ ] 바뀔 내용(diff)이 이해된다 (무엇이 왜 바뀌는지)

- [ ] settings.json의 기존 내용·들여쓰기가 그대로다
- [ ] 안내대로 커밋하면 팀원 PC에서도 적용된다 (팀원 1명 확인)
- [ ] 되돌리기 후 `git status`가 깨끗하다 (원본과 다른 파일 0건)
