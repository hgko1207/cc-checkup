화면을 새로 정리하고, 혼자 쓰는 폴더와 팀 저장소를 나눠 점검하는 버전입니다.

## 받을 파일

| 운영체제                      | 파일                         |
| ----------------------------- | ---------------------------- |
| Windows                       | `cc-checkup-setup-1.1.0.exe` |
| macOS Apple Silicon (M1 이후) | `cc-checkup-1.1.0-arm64.dmg` |
| macOS Intel                   | `cc-checkup-1.1.0-x64.dmg`   |

코드 서명 전이라 처음 실행할 때 경고가 뜹니다.

- Windows: "Windows의 PC 보호" 창에서 **추가 정보 → 실행**
- macOS: 앱을 **오른쪽 클릭 → 열기** (macOS 판은 아직 실제 맥에서 확인하지 못했습니다)

1.0.0을 쓰고 있었다면 새 설치 파일을 그대로 실행하면 됩니다. 최근 폴더와 고른 기준 파일은 그대로 남습니다.

## 바뀐 것

- **혼자 / 팀**: 폴더를 열면 혼자 쓰는 폴더인지 팀 저장소인지 앱이 추천합니다. 팀 설정이 커밋돼 있으면 팀으로 봅니다. 바꾸면 그 폴더에 기억합니다.
  - 혼자: 고치면 끝납니다. 커밋·보내기 단계와 팀 전용 항목이 빠지고, 내 PC 전용 설정(`settings.local.json`, `~/.claude/settings.json`)의 보호도 인정합니다.
  - 팀: **1 고치기 → 2 커밋 → 3 팀원에게 보내기**까지 해야 끝납니다.
- **처음 화면**: 최근 점검한 폴더와 점수, 사용 방법 3단계가 보입니다. 왼쪽 위 이름을 누르면 처음 화면으로 돌아갑니다.
- **할 일 카드**: 제목이 "무엇이 위험한가" 문장이고, 바로 아래에 할 일과 버튼이 있습니다. 줄마다 그 할 일만 고쳤을 때 오르는 점수를 보여 주며, 미리 보기의 점수와 같습니다.
- **추천 세팅 탭**: 할 일을 기본 보호·작업 방식·팀 공유 묶음으로 정리해 보여 줍니다. 모두 갖추면 한 줄로 알려 줍니다.
- **커밋 확인창**: 커밋할 파일 목록과 "커밋한 뒤에는 앱의 되돌리기를 쓸 수 없습니다" 경고를 먼저 보여 줍니다. Ctrl+Enter로는 커밋되지 않고 직접 눌러야 합니다.
- **원격 저장소가 없는 팀 폴더**: 연결 방법을 알려 주고, [보내기는 직접 할게요]로 마칠 수 있습니다.
- **용어**: "기본 기준", "사내 기준 파일", "Claude 설정 파일", "위험 명령 검사(훅)"로 통일했습니다.
- **접근성**: Windows 고대비 모드에서도 혼자/팀 선택과 점수 막대가 보입니다. 화면 낭독기가 할 일 줄을 자연스럽게 읽습니다.
- **고친 문제**: 한 건만 미리 볼 때 커밋 뒤 점수를 전부 고친 점수로 보여 주던 문제를 고쳤습니다.

## 준비물

- **Claude Code** 설치와 로그인: "Claude로 반영" 버튼에 필요합니다. 앱 왼쪽 아래에 상태가 보입니다.
- **git**: 커밋과 팀원에게 보내기에 필요합니다.
- **Node.js**: 위험 명령 검사(훅)를 넣으면 그 PC에 필요합니다.
- **사내 기준 파일**: TF가 공유 폴더에 둔 `standard.json`을 처음 화면의 [사내 기준 파일 고르기]로 지정합니다. 지정하지 않으면 기본 기준으로 점검합니다.

## 알려진 한계

- .env 차단 규칙은 `grep -r`나 스크립트로 읽는 경우까지는 막지 못합니다. 위험 명령 검사(훅)를 함께 쓰세요.
- 자동 업데이트는 없습니다. 새 버전이 나오면 TF가 기준 파일에 버전을 올리고, 앱 맨 위에 알림이 뜹니다.

문제나 헷갈리는 문구는 TF에 알려 주세요.
