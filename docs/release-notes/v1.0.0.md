Claude 세팅 점검 첫 시범 버전입니다. 폴더를 고르면 사내 Claude 표준과 비교해 점수와 고칠 점을 보여 주고, 확인 후 바로 고치거나 Claude로 반영합니다.

## 받을 파일

| 운영체제                      | 파일                         |
| ----------------------------- | ---------------------------- |
| Windows                       | `cc-checkup-setup-1.0.0.exe` |
| macOS Apple Silicon (M1 이후) | `cc-checkup-1.0.0-arm64.dmg` |
| macOS Intel                   | `cc-checkup-1.0.0-x64.dmg`   |

코드 서명 전이라 처음 실행할 때 경고가 뜹니다.

- Windows: "Windows의 PC 보호" 창에서 **추가 정보 → 실행**
- macOS: 앱을 **오른쪽 클릭 → 열기** (macOS 판은 아직 실제 맥에서 확인하지 못했습니다)

## 준비물

- **Claude Code** 설치와 로그인: "Claude로 반영" 버튼에 필요합니다. 앱 왼쪽 아래에 설치·로그인 상태가 보입니다.
- **Node.js**: "위험 명령 차단 훅"을 넣는 경우 그 PC에 필요합니다.
- **사내 표준 파일**: TF가 공유 폴더에 둔 `standard.json`을 [점검 기준] 탭의 [표준 파일 바꾸기]로 지정합니다. 지정하지 않으면 기본 표준으로 진단합니다.

## 할 수 있는 것

- **점검 결과**: 맨 위에 지금 상태와 할 일을 한 문장으로 보여 줍니다(예: "5개 고치고 커밋하면 팀 기준을 통과합니다"). 점수 막대에 지금·고친 뒤·커밋한 뒤 점수와 80점 선이 보입니다.
- **할 일 목록**: 같은 고치기로 풀리는 문제는 한 줄로 묶고, 줄마다 고치면 오르는 점수를 보여 줍니다. 줄을 누르면 왜 문제인지, 고치면 무엇이 바뀌는지, 예시가 펼쳐집니다. 통과한 항목은 접어 둡니다.
- **점검 기준**: 지금 적용 중인 표준, 점수 규칙, 이 폴더에서 보는 항목 전체와 통과 기준·감점·결과를 보여 줍니다. 보안(.env 차단·우회 모드·위험 명령), 팀 공유(커밋), CLAUDE.md, 필수 파일, 사내 플러그인.
- **폴더 종류**: 개발 저장소인지 문서·기획 폴더인지 자동으로 판별하고, [점검 기준] 탭에서 바꿀 수 있습니다.
- **바로 고치기**: .env 차단 규칙, 우회 모드 막기, 위험 명령 차단 훅, plan.md 템플릿, 사내 플러그인 설정을 넣습니다. 쓰기 전에 바뀔 내용을 파일별로 보여 주고, 고칠 항목을 골라 적용할 수 있습니다. 적용 후 점수 변화를 알려 줍니다.
- **Claude로 반영·만들기**: Claude Code가 폴더를 읽고 CLAUDE.md나 DESIGN.md를 씁니다.
  - 실행 전에 고칠 파일·걸리는 시간·사용량을 보여 주고 [Claude 실행]을 눌러야 시작합니다. 실행 중에는 경과 시간과 [중단]이 보입니다.
  - Claude는 대상 파일만 고칠 수 있습니다. 명령 실행과 .env 읽기는 막혀 있습니다.
  - 바뀐 내용을 확인하고 [적용]하거나 [취소]합니다.
  - 근거를 찾지 못한 규칙은 지어내지 않고 TODO로 남깁니다.
  - Claude 작업이 둘 이상이면 [Claude로 모두 처리]로 하나씩 이어서 실행합니다. 결과마다 적용할지 고른 뒤 다음으로 넘어갑니다.
  - 한 번에 30~40초, Claude 사용량 약 $0.1~0.3어치입니다(작은 저장소 기준). 구독 요금제면 사용 한도에서 차감되고, API 키로 쓰면 그만큼 청구됩니다. 이 앱이 따로 받는 돈은 없습니다.
- **되돌리기**: 적용한 변경은 [마지막으로 고친 것 되돌리기]로 원래대로 돌립니다. 원본은 `~/.cc-checkup/backups/`에 남습니다.
- **점수**: 100점에서 위험 1건마다 15점, 주의 1건마다 5점을 빼고, 목표는 80점입니다. 80점 이상이고 팀원에게 보내면(push) "준비됨"이 됩니다.
- **키보드**: Ctrl+O 폴더 열기, F5 다시 점검, Ctrl+Enter 주 버튼(바로 고치기·확인창의 적용), Ctrl+1·2 탭 옮기기, Esc 닫기.
- **용어 풀이**: 할 일을 펼치면 그 줄에 나온 용어(훅, 권한 우회 모드 등)를 풀어 주고, [점검 기준] 탭에 전체 목록이 있습니다.
- **리포트 저장**: 결과를 마크다운으로 저장해 TF에 공유합니다.

## 적용한 뒤

`.claude/settings.json`, `.claude/hooks/`, CLAUDE.md처럼 바뀐 파일을 **git에 커밋해야** 팀원 모두에게 적용되고, 커밋 전에는 "커밋 여부"가 위험으로 남아 점수가 덜 오릅니다. 적용한 뒤 [변경 커밋하기]를 누르면 앱이 만든 파일만 골라 커밋합니다(따로 스테이징해 둔 변경은 섞지 않습니다). 커밋한 뒤에는 "커밋됨 · 아직 안 보냄"으로 표시되고, [팀원에게 보내기]로 확인을 거쳐 push까지 할 수 있습니다. 커밋한 뒤에는 앱의 되돌리기를 쓸 수 없습니다(git으로 되돌리세요). 터미널에서 직접 하려면 "직접 하려면"에서 명령을 복사하세요.

## 알려진 한계

- .env 차단 규칙은 `grep -r`나 스크립트로 읽는 경우까지는 막지 못합니다. 차단 훅을 함께 쓰세요.
- 문서·기획 폴더 기준은 추정으로 만든 것이라 시범에서 바뀔 수 있습니다.
- 새 버전이 나오면 TF가 표준 파일에 버전을 올리고, 앱 맨 위에 알림이 뜹니다. 자동 업데이트는 없습니다.

문제나 헷갈리는 문구는 TF에 알려 주세요.
